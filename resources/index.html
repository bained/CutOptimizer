Optimization settings

Optimization settings help

Cutting direction

Optimal lets the engine decide how to pack the sheet. The other two force every cut to run along one direction, which suits a sliding table saw or a beam saw that only cuts one way.

Grain direction

Tick this when the material has a visible grain or a veneer that must run one way. Every part then keeps the orientation you entered, so 600 x 400 and 400 x 600 are no longer interchangeable.

Minimum reusable off-cut

Leftovers smaller than this are counted as scrap instead of reusable stock. Set it to the narrowest strip you would actually put back on the rack.
